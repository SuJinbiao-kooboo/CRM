## 4. 采集与整理方法

1. 从 `https://www.nvidia.com/gtc/sponsors/` 加载 RainFocus 展商目录，捕获 `/api/exhibitors` 返回的完整 JSON（435 条）。
2. 解析展商名称、赞助级别、简介、官网、展位号、展商 ID。
3. 访问企业官网首页及 contact/about/company/locations 等页面，提取公开邮箱、电话；对 403/JS 渲染站点补充无头浏览器抓取。
4. 国家/区域以企业总部公开信息为准；无法确认的保留“待核实”，未做猜测。
5. 主营业务按企业简介、官网业务描述和产品线归类；“是否IT配件或服务器相关”按硬件/基础设施属性分级。

## 5. 使用建议

- 找**纯硬件/配件/服务器供应商**：筛选 `相关度说明` 以“核心：”开头的 135 家，或直接使用 `GTC2026_核心硬件与配件.csv`。
- 找**云/算力/数据中心合作方**：筛选 `相关度说明 = 相关：云/算力租赁/数据中心`。
- 做市场地图：按 `所在国家/区域` + `主营业务分类` 透视；Excel 已按赞助级别/国家排序。
- 联系前请再次核对官网最新联系方式；部分邮箱为媒体/投资者关系/安全响应邮箱，不一定是销售邮箱。

## 7. 复现方式

```bash
cd tools/gtc-scraper
npm install
node fetch.js            # 捕获 GTC 展商 JSON
node fetch_sites.js      # 抓取企业官网信息
node fetch_contacts.js   # 补充联系邮箱/电话
node build_final2.js     # 生成最终结构化数据
python make_output.py    # 生成 CSV/XLSX
```

说明：脚本仅访问公开页面，已做并发与超时控制；如官网改版，选择器和字段可能需要调整。
